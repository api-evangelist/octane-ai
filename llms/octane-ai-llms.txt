# Octane AI

> Octane AI is an AI-powered quiz and product-recommendation platform for Shopify merchants. It turns storefront browsers into buyers with no-code personalized quizzes, zero-party data capture, and its CORE-1 recommendation engine. Its developer surface is client-side: an embeddable quiz widget with a documented browser JavaScript event API, custom CSS/JS hooks, and a per-account API key + webhook secret for integrations and automation. There is no public REST API or OpenAPI.

## Client-side JavaScript events (octane.quiz.*)
- octane.quiz.completed — shopper reaches the quiz results page (answers, opt-in, recommendations)
- octane.quiz.accessed — shopper accesses a quiz results page URL
- octane.quiz.questionLoaded — a quiz question loads
- octane.quiz.questionAnswered — a quiz question is answered
- octane.quiz.addToCart — add-to-cart button pressed
- octane.quiz.addToCartError — add-to-cart action failed
- octane.quiz.viewCart — view-cart button pressed
- octane.quiz.goToCheckout — checkout button clicked
- octane.quiz.goToProductPage — product-page button clicked
